# 信贷违约预测项目 · 环境配置文档

**项目**：基于用户历史数据与行为特征的信贷违约预测模型
**周期**：2026/8/31 – 2026/9/27 ｜ **文档版本**：v1.0（2026/8/31）

## 1. 项目概述
本项目基于阿里天池信贷违约数据集，构建机器学习模型预测借款人违约概率，为金融机构风控决策（放款、定价、额度）提供数据支持。

## 2. 开发环境

| 项目 | 配置 |
|---|---|
| 操作系统 | macOS（Apple Silicon, arm64） |
| Python | 3.13.0（虚拟环境 `.venv`） |
| 开发工具 | VS Code（Jupyter 扩展），PyCharm 备用 |
| 虚拟环境 | `.venv`（位于项目根目录） |

## 3. 依赖库及版本

## 4. 环境搭建步骤
1. 创建虚拟环境：`python3 -m venv .venv`
2. 激活环境：`source .venv/bin/activate`
3. 安装依赖：`pip install pandas numpy matplotlib seaborn scikit-learn xgboost jupyter`
4. VS Code 中选择解释器为 `.venv`，Jupyter 内核使用 ipykernel 7.3.0

## 5. 遇到的问题与解决
**问题**：`xgboost` 导入报错 `XGBoost Library (libxgboost.dylib) could not be loaded`。
**原因**：macOS 上 xgboost 依赖 OpenMP 运行时（`libomp.dylib`），系统未安装。
**解决**：执行 `brew install libomp` 后，`import xgboost` 验证通过（版本 3.4.1）。
